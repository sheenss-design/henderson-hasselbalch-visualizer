Henderson-Hasselbalch 방정식 시각화

pH, HCO3-, pCO2 슬라이더로 연동 변화를 확인하세요

pH = 6.1 + log10( [HCO3-] / (0.03 × pCO2) )
추정 tCO₂ 25.2 mmol/L
(HCO₃ 24.0 + 용존 CO₂ 1.2)
정상 (Normal)
HCO3 : 용존 CO2 비율 = 20.0 : 1 (정상 ≈ 20:1)
정상 범위: pH 7.35–7.45 · HCO3 22–26 mmol/L · pCO2 35–45 mmHg
추정 tCO₂ ≈ HCO₃ + 0.03 × pCO₂ (혈액화학 검사의 total CO₂에 가까운 근사값)
모드를 선택하면 해당 변수가 자동 계산되고, 나머지 두 슬라이더를 움직여 변화를 관찰하세요.

사용 방법

  • pH 계산 모드: HCO3와 pCO2를 조절하면 pH가 자동으로 변합니다.
  • HCO3 계산 모드: pH와 pCO2를 조절하면 HCO3가 자동으로 변합니다.
  • pCO2 계산 모드: pH와 HCO3를 조절하면 pCO2가 자동으로 변합니다.
  • 프리셋을 눌러 전형적인 산-염기 장애 상태를 빠르게 확인해 보세요.

이 도구는 교육 목적으로만 사용하세요. 실제 환자 진단에 사용하지 마세요.
